The data is already there. The papers aren't.

Across 60 natural-aquatic metagenome taxids, public archives hold 36,806 BioProjects and 1.34 Pbp of sequence — ocean, lake, river, estuary, ice, spring and groundwater. Most of it has never appeared in a paper. OMC exists to close that gap.

Bars put published projects at the baseline so their counts stay comparable across years; the grey “0 papers” segment sits on top. Publication evidence is the union of Europe PMC accession matches, NCBI BioProject→PubMed links and ENA project cross-references — it misses citations that appear only in paywalled text or supplements, so these are conservative. 55% of aquatic BioProjects come from the DOE Joint Genome Institute, which registers one BioProject per sample; the default view excludes them so the denominator reflects distinct research efforts. Projects spanning two environments are counted in both. 2025–2026 are incomplete — papers may still be in the pipeline. Sources: ENA Portal API, Europe PMC, NCBI E-utilities (19 Aug 2026).

How It Works

  1. Submit data

    Enter a public sequence accession and select an analysis pipeline

  2. Pipeline runs on HPC

    Standardized Nextflow pipelines process the sequences

  3. Autoresearch explores the results

    An AI agent interrogates the pipeline outputs, tests each claim against the data, and keeps only what verifies

  4. Draft generated

    AI writes a manuscript from the verified findings

  5. Review via GitHub

    Peer review happens through pull requests
